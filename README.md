## About Me

I work as a **Corporate Java Trainer** and focus on teaching how real software is built in companies, not just how to write code.

I mainly work with **Java, Spring Boot, Angular, React and backend systems**, and I enjoy helping people understand how things work behind the scenes — from database design to secure APIs and deployment.

Most of my work is around building **practical, real-world projects** that feel close to what developers see in actual jobs.

## What I Focus On

- Database design and SQL
